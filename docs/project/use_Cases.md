# PartyHause — Use Cases

Version: 1.1
Date: October 21, 2025

This document lists 20 concrete scenarios showing how different users use PartyHause across the three pillars: Planning, Engagement, and Memory. Each scenario includes: persona, event type, goals, step-by-step flow by pillar, success criteria, and short notes.

---

1) Social Butterfly — Rooftop Birthday Bash
Persona: Social Butterfly (age 25-35)
Event: Large rooftop birthday (60 guests)
Goal: Create a high-energy, shareable party with minimal friction for guests.

Planning
- Use PartyHause's event wizard to create the event in < 10 minutes using a "Birthday — Large" template.
- Import contact list and send branded email invites with RSVP tracking and ticket QR codes.
- Coordinate with caterer via vendor workspace and set timeline in the PartyBoard.

Engagement
- Enable live poll for song voting and a photo scavenger hunt with real-time scoreboard.
- Host uses presenter mode to display live scoreboard and highlight guest photos.
- Run a short trivia game mid-party with prizes to boost energy.

Memory
- Automatic gallery collects photos uploaded by guests and the host's camera.
- PartyHause generates a 60-second highlight reel with music within 24 hours.
- Guests receive a post-event thank-you email with a collated album link.

Success Criteria
- 80% RSVP rate, 70% guest engagement in at least one activity, highlight reel shared on social.

Notes: Monetize with "Advanced Games" add-on and post-event photo print partners.
