## 📋 **Production Guidelines for All Videos**

### **Visual Style:**
- **Clean, modern UI shots** (no clutter)
- **Smooth transitions** (swipe, fade, zoom)
- **Vibrant colors** (match app's purple/green scheme)
- **Real hands** interacting with phones (not floating screenshots)
- **Quick cuts** (max 3 seconds per shot)

### **Audio:**
- **Upbeat, energetic music** (royalty-free)
- **Clear voiceover** (professional or AI-generated)
- **Sound effects** on key actions (tap, vote, confetti)
- **Captions on all text** (80% watch without sound)

### **Branding:**
- **App icon** visible in first 3 seconds
- **Color scheme** consistent (purple primary, green accent)
- **Logo watermark** in corner (subtle)
- **End card** with download buttons + social handles

### **Technical Specs:**
- **Resolution:** 1080x1920 (9:16 vertical for mobile)
- **Frame rate:** 30fps minimum
- **Length:** 15-60 seconds (algorithm-friendly)
- **File format:** MP4, H.264 codec
- **Captions:** Hardcoded + separate .srt file

## 🎯 **Screen Recording Checklist**

### **Before Recording:**

1. ✅ **Clean data** - Use mock data, no real names/emails
2. ✅ **Full battery** - Show 100% battery icon
3. ✅ **Good signal** - Full WiFi/cellular bars
4. ✅ **Hide notifications** - Enable Do Not Disturb
5. ✅ **Time display** - Set to round number (9:41 AM - iPhone default)
6. ✅ **Screen brightness** - 80-100%
7. ✅ **Clear animations** - Slow down if needed for clarity

### **During Recording:**

1. ✅ **Smooth interactions** - No rushed taps
2. ✅ **Pause on key screens** - Let viewers absorb info
3. ✅ **Steady hands** - Use tripod or stable surface
4. ✅ **Clean taps** - Deliberate, visible touches
5. ✅ **Show results** - Don't cut mid-action

### **After Recording:**

1. ✅ **Speed up** boring parts (navigation)
2. ✅ **Slow down** key moments (results, animations)
3. ✅ **Add overlays** (arrows, circles, text callouts)
4. ✅ **Color grade** - Enhance app colors
5. ✅ **Export at highest quality**
