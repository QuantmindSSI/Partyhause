## 📊 Key Interaction Patterns

### **For Hosts:**
1. **Create** event with AI template
2. **Invite** co-planners and assign roles
3. **Find** vendors through marketplace
4. **Approve** quotes and payments
5. **Monitor** progress in real-time
6. **Review** completions and rate vendors

### **For Co-Planners:**
1. **Accept** invitation
2. **Browse** available tasks
3. **Self-assign** or get assigned tasks
4. **Update** status and add notes
5. **Collaborate** via comments
6. **Complete** assigned work

### **For Vendors:**
1. **Receive** quote requests
2. **Submit** quotes with details
3. **Get approved** and added to team
4. **Update** checklist and status
5. **Upload** documents/photos
6. **Message** host for clarifications
7. **Complete** service and get paid

### **For Task Owners:**
1. **Receive** assignment notification
2. **View** task details and context
3. **Update** status simply
4. **Ask** questions via comments
5. **Upload** progress photos
6. **Mark** complete when done
