PARTYHAUSE HELP

Support

Help for the current iPhone private-event host app and browser RSVP.

Contact Support

Email account, invitation, RSVP, privacy, or deletion questions to:

support@partyhause.com

Include the app version, iPhone model, and a description of what happened. Do not send your password, verification token, reset token, or RSVP link.

Account Help

I have not received a verification email

Return to Sign In, enter the same email and password, and use Resend Confirmation when prompted. Check the address and junk folder. The response is intentionally the same whether an address is registered.

I forgot my password

Choose Forgot Password on Sign In. The browser reset link expires after one hour and works once. Completing a reset revokes existing sessions. Sign in again with the new password.

I want to sign out

Open Account and choose Sign Out. PartyHause revokes existing sessions for the account and clears private data held by the app.

I want to delete my account

Open Account, choose Delete Account, review the impact, re-enter your password, and type DELETE. Access is revoked immediately. The app retains an opaque receipt so it can show or retry deletion status without retaining your account session. Primary deletion completes within 24 hours.

Events, Guests, and Invitations

Create or change an event

Use the add button on the event dashboard to create a private event. Open the event to edit, publish, cancel, or delete it. An internet connection is required for each saved change.

Add guests and send invitations

Open an event's guest list and manually enter a name and email address. Each event supports at most 50 guests. The Invitations screen sends PartyHause's fixed email only to guests you select.

A guest cannot RSVP

The guest should open the complete HTTPS link from the invitation in a current browser. A link can be expired or revoked after the event is cancelled, the guest is removed, or the host account is deleted. Support cannot ask for the full RSVP link; the host can send a fresh invitation when the event remains active.

Check-in is unavailable

Only a guest with an accepted RSVP can be checked in. Open the event's guest list and use the visible Check In action. Check-in is manual and does not use a camera or code scanner.

Privacy Requests

Email support@partyhause.com for access or correction help. Permanent account deletion starts and completes in the app without a support request. Read the Privacy Policy for retention and guest-data details.
